Project Alpha is a command-line interface that integrates advanced AI agents into the daily local development cycle.

### Key Capabilities
- **Local AST Parsing**: Parses TypeScript AST to intelligently identify function and class scopes before generating modifications.
- **Contextual Ingestion**: Reads whole workspaces and builds structured indexes for faster reference.
- **Auto-linting Cycles**: Automatically runs npm scripts, captures console errors, and self-corrects the code in a loop.
