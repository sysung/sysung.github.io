This portfolio is built to be clean, fast, and extremely easy to maintain. 

### Key Features
* **Astro Framework**: Highly performant, rendering zero-JS static HTML by default.
* **Content Collections**: Type-safe rendering of projects directly from markdown files.
* **Glassmorphic UI**: Beautiful CSS properties using custom gradients, backdrops, borders, and modern fonts (Outfit and Inter).
* **CI/CD Built-in**: Automatically builds and deploys to GitHub Pages via GitHub Actions on every `git push`.
